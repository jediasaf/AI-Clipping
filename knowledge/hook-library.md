# Hook Library

**Entry requirement: real performance data.** A hook enters this library only after it has
been published and measured. Hypotheses live in `experiments/experiment-log.md`, not here.

The Hook Strategist may propose hooks freely. It may not write them here until the numbers
exist. This separation is the point of the file — the library is the evidence base we scale
from, and an untested hook sitting in it looks identical to a proven one three weeks later.

## Format

```
### HOOK-###  "<the hook text>"
- **Type:** CURIOSITY / SHOCK / CONTRARIAN / STAKES / STORY / STATUS / MONEY / CONFLICT / RESULT-FIRST
- **Clip IDs used on:**
- **N:**
- **Median views:**
- **Completion rate:**
- **Verdict:** WINNER / NEUTRAL / LOSER / INSUFFICIENT DATA
- **Caveats:** (confounds, platform, campaign, posting time)
```
