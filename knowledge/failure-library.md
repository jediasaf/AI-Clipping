# Failure Library

Confirmed failures, kept deliberately. We will generate more failures than successes, they are
cheaper to learn from, and they are the fastest way to stop wasting editing hours.

Record here: clips that flopped with a diagnosed cause, campaigns that rejected our work,
formats we killed, hooks that underperformed, and process mistakes.

## Format

```
### FAIL-###  <short name>
- **Date:**
- **What we did:**
- **What happened:** (numbers)
- **Diagnosed cause:** (with confidence — VERIFIED / INFERENCE)
- **Alternative explanations:**
- **What we stopped doing as a result:**
```

A failure without a diagnosed cause is not yet a lesson — but log it anyway, since three
undiagnosed failures often reveal a pattern the first one could not.

Do not record a single flop as a rule. One clip at low views is variance, not evidence.
