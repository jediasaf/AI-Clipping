# Clipping Playbook

**What this file is:** what we currently believe about making clips that perform, based on
**our own** performance data.

**What this file is not:** a collection of best practices from the internet, or things that
sound true.

## Rules for this file

1. Every entry carries its **sample size** and the **date** the evidence was gathered.
2. An entry may only be added by the Performance Analyst, after real data exists.
3. When new data contradicts an entry, **revise or retire it**. This is a record of current
   belief, not an archive.
4. N < 5 is anecdotal and does not earn an entry. N 5–20 may be entered as a weak signal,
   clearly marked.

The temptation this file exists to resist: after a clip does well, it is very easy to write
down why. That explanation is usually wrong, and once written down it starts directing
production. An empty playbook is honest. A playbook full of confident guesses is worse than
no playbook, because we would scale our guesses.
